# @yario-ai/integration-sdk

Official Node.js client for the Yario Partner Integration API. See the [integration guide](https://docs.yario.ai/docs/developers/integrations), [API reference](https://docs.yario.ai/api-reference/developers/integrations/api-reference), and [runnable payment example](https://github.com/yario-ai/yario-payment-partner-demo).

The package includes a typed API client, bounded retries with idempotency, structured API errors and raw-body webhook verification.
